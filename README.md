# Weekly Python Exercises

A running collection of self-directed, weekly Python exercises applying quantitative methods to product and strategy questions. Each week explores a different technique — curve fitting, forecasting, statistical benchmarking — applied to a product-ops-relevant scenario, with results interpreted for decision-relevance rather than left as raw output.

## Purpose

This repo exists to build and demonstrate applied data science skills through consistent, hands-on practice — bridging a product/strategy background with growing technical rigor. Each exercise is small by design; the value is in the cadence and the interpretation, not any single script's complexity.

## Structure

Each week has its own folder, containing:
- A script with the exercise's code
- A `README.md` explaining that week's purpose, the skill practiced, and the key finding
